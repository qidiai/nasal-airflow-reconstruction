## 4. 求解验收与收敛证据

### pN-Med（✅ 通过）
- `log.simpleFoam` 明确输出 **`SIMPLE solution converged in 182 iterations`**。
- 末步残差：p 初残差 9.67e-05、Ux 初残差 2.89e-05，均 **< 1e-4**（residualControl 门槛）。
- ΔP = 8.30 Pa，符合"正常人 <20 Pa @15 L/min"预期。
- 分区通气：嗅区 0.31 / 中鼻道 4.85 / 下鼻道 9.84 L/min（合计 15.0 L/min）。
- checkMesh：`Mesh OK`，非正交度 max 0 / avg 0，长宽比 max 1.63，偏斜 2.0e-13。

### pN-Lat（⚠️ 未收敛，如实报告）
- `log.simpleFoam` 跑满 **1500 步（endTime）**，**无收敛输出**。
- 末步残差：p 初残差 9.02e-02、Ux 初残差 1.50e-02——**较 1e-4 门槛高 2~3 个数量级，且末 500 步呈平台振荡（非下降）**。
- ΔP = 116.28 Pa，**远超 20 Pa 阈值**；Umax = 13.86 m/s（出口射流特征，物理不可靠）。
- 分区通气受回流污染（嗅区 12.1 L/min 占 80%，明显异常）。
- **根因推断**：出口面积仅 74.9 mm²（约为鼻瓣面积 242.5 mm² 的 1/3），15 L/min 下出口平均流速 3.34 m/s、局部射流更强，诱发非定常/分离流动；稳态层流 SIMPLE 无法收敛（属物理/数值双重问题，非代码 bug）。
- **建议返工方向**（赛后）：出口加延长段消除截断面射流；改用 RAS 湍流模型（k-ω SST）或瞬态求解；核查出口截断位置是否落在狭窄段。
