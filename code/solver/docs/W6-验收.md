# W6 验收报告 v1：压力 PCG 预条件子 SGS→IC(0)（正确性达成，性能部分达成）

> 日期：2026-10-19。双席审稿：GLM53 + deepseek-flash（均 GO-with-conditions）。
> 本文档记录 W6 首轮实施的完整事实：一个真实 bug 的定位与修复、全部验证结果、性能实况与下一步选项。

## 1. 背景与根因（实证）

- 压力方程 PCG+SGS 每次外层迭代 ~537 次线性迭代（`out/l3b-001.log`：389/550/548/.../537，20 外层实测 57.4s），占总耗时 ~97%
- OF 同类系统 GAMG ~14 次（但其跑在 relTol 0.05，比我们的 1e-3 松——非同容差对比）
- 根因：SGS 对病态压力系统（rAU ~80 倍变幅致条件数恶化）预条件能力弱

## 2. 实施内容（~750 行，linalg.rs + simple.rs 调用点）

1. IC(0) 分解（IKJ 式，pattern-based，provenance: Meijerink & van der Vorst 1977 / Saad §10.3.1）
2. Jacobi 对角缩放 D^(-1/2)AD^(-1/2)（治 rAU 跳变）
3. 零主元统一 shift（0/1e-12/1e-10/1e-8/1e-6 阶梯，禁 SGS 回退——双席红线）
4. 常数模 deflation（`FLOWSCOPE_DEFLATE=1`，默认关，164 面出口的唯一常压模）
5. A/B 开关 `FLOWSCOPE_PRECOND=sgs|ic0`，**覆盖两处调用点**（simple.rs:342 初始化 + :571 主循环），**默认 sgs**（生产路径零变化）
6. pLin 全量统计（`FLOWSCOPE_VERBOSE_ALL=1`：median/mean/max/converged/breakdown/cap_hits）
7. `pcg_equiv_check`（C1 解不变性：同 A/b/x0 双预条件子解到 1e-10 比对）+ CSR/RHS 落盘（`FLOWSCOPE_DUMP_PCSR`/`FLOWSCOPE_DUMP_PB`）
8. SPD/M-矩阵预检（min diag>0、off-diag≤0、对角占优度，替代原方案的对称性检查——对称是构造保证）

## 3. 发现的真实 bug 与修复（本轮最有价值产出）

**症状**：IC(0) 首测大系统 Time=1 全 NaN；小系统 pLin 3000 打满零进展。
**根因**：`Ic0::apply` 回代把 `scale[i]` 提前乘进中间量 `z[i]`——回代解 `Lᵀu=y` 时后续行需要未缩放的 `u[i]`，预条件子因此既非 A⁻¹ 也非对称，PCG 停滞、大系统叠加数值崩溃。
**判据**：单元隔离（1D Laplacian）——修复前 `L·Lᵀ=Â` 精度 2e-16 但 `apply` 误差 0.52；修复后 apply 误差 6e-15。
**教训**：分解对 + 应用错 = 经典故障模式；单元隔离协议（L·Lᵀ≈Â、M⁻¹e_i 对参考、M⁻¹ 经验 SPD）是定位此类 bug 的正确方法，已沉淀为三个单测（`cargo test --release` 3/3 过）。

- **C. AMG 正式立项（W7）**：多重网格是唯一能达到 GAMG 级（我们容差下预期 30-60 迭代）的路线；500-1000 行，需独立方案+双席审稿

### 抓出的真 solver bug：提前收敛跳过最终写出（已修）

- **症状**：case-026 在 ic0+deflation 下 ~100-199 步即 residualControl 双达标提前 `break`，而 `write_snapshot` 只在循环内按 `write_interval`（=1500）触发——提前退出 = 末态 fields_*.vtk 从未落盘 → 下游 `build_metrics` FileNotFoundError（驱动回报 rc=-997）。SGS 旧默认下该例 1500 步不收敛，此 bug 潜伏未暴露。
- **根因**：`simple.rs` 求解循环的写出语句在 residualControl 检查之后，提前 break 跳过写出；循环后无兜底写。
- **修复**：循环后补兜底——`if write_interval > 0 && self.iter % write_interval != 0 { write_snapshot(dir, self.iter) }`（末迭代未写过则补写；早停也是完成态）。
- **验证**：修复后 L3-026 重跑 rc=0、iter 199 提前收敛、fields 正常落盘、dP +1.446% PASS。
- **教训**：加速→提前收敛→暴露潜伏写出路径缺陷——门禁跑全案例的价值案例；预条件子只改收敛路径不改不动点，但工程路径（写出/快照）必须覆盖所有退出路径。

### 结论

IC(0)+deflation@1e-3 作为新默认：**数值不回退（7/7，多数例偏差 <0.5%；pA 反而更贴近 OF 归档）+ 墙钟 ~1.79x + 部分算例提前收敛（求解效率的额外证据）**。求解器写出路径的兜底缺陷已修复并经门实证。W6 至此收官。
