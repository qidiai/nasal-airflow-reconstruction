# W7 验收报告：聚合两层粗空间（M2）——正确性全过，生产规模性能为负（opt-in 保留）

| 维度 | 结果 |

两层统计（case-001）：coarse_size 5182（9.6%）、builds 20、degraded 0；构建总计 0.641s/20 外层=**32ms/外层（占 1.4%，不是瓶颈）**；粗解 apply 5.003s/7070 次=**0.71ms/次**；但每迭代摊销 +2.9ms——粗解+P scatter/gather+摊销非压力工作吃掉了迭代收益。

## 根因：探针的 ~48% 砍幅没有迁移到生产口径

- 探针（Python，真实矩阵）在**绝对 1e-9 严口径**（导出 rhs 微小所致）下砍 46-50%
- 生产口径（相对 1e-3）下 Rust 实测只砍 24%——相对容差提前停止，粗空间要修的模变少
- 双席审计预判兑现：qwen"M1/M2 大规模重构小收益"、GLM"构建成本吞掉迭代收益"——unsmoothed 聚合的粗空间质量不足以同时买到迭代与墙钟

## 结论与下一步选项

unsmoothed aggregation two-level 在此规模此成本结构下**上限 ~1.2-1.3x over ic0+deflate**（总 ~2.1-2.3x），够不到 2.5x 目标。剩余选项：
1. **smoothed aggregation**（滤波传递算子，粗空间质量↑→砍幅↑）——中等构建，下一个合理台阶
2. **AMG 正式立项**——唯一到 GAMG 级的路线，1-3 周
3. **转 WSS 准确度轨道**（±8% 短板 + dev2 合规缺口）——准确度账上还有真收益
4. **接受现状**（1.79x + opt-in two-level），求解器加速线暂歇
