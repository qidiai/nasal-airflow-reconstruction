# FlowScope 求解器等价性报告（L0–L3）

> 口径：`pipeline/docs/contracts/numerical-contract.md` v1.0；参照 OpenFOAM v2406 `simpleFoam`；
> 清洁室实现（只读 OF 用户指南与归档 log/metrics，未读 OF 源码）。
> 本报告所有数值均来自 `solver/out/` 下的日志/场文件，可复跑。

## 0. 判定标准（规划 v2.3.2 §4）

| 级 | 名称 | 容差/标准 |
|---|---|---|
| L0 | Poiseuille/Backstep 解析解 | 中心速度 <1%、ΔP <2% |
| L1 | 与 OpenFOAM 指标 | ±2% vs 归档标准取值（pA ΔP=18.45 Pa、pB ΔP=44.9067 Pa） |
| L2 | 场相关 | 速度场 Pearson 相关 >0.98（逐病例 VTK 对拍） |
| L3 | 批量回归 | baseline27 22 个成功例全部跑通，dP 漂移 <2%（5 个 OF DIVERGED 例除外，作韧性记录） |
| — | 稳定性前置 | flux 闭合 <1%、checkMesh 0 errors |

求解设置：`bounded Gauss linearUpwind grad(U)` + unlimited（契约方案）、PCG-SGS、`
p_reltol=1e-3`（L1/L2/L3 统一紧 p 口径）、Run-A `flowRateInletVelocity`。
