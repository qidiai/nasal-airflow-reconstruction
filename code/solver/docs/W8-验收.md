## 1. dev2 合规项（D-6 关闭）

- **实现**：张量恒等式 `dev2(A) = A − (2/3)·tr(A)·I`（A=T(∇U)）显式源项，fvm.rs `dev2_face_source`，接入 assemble_momentum 内面（L312 邻域）与 vel_fixed 边界面（L369 邻域）——与 nonorth_source 同架构（显式 source，隐式矩阵不动保对称）
- **双席修正的方案书错误**：dev2 不是"面法向梯度差的二阶修正"（原方案书错），是张量恒等式；且**严禁实现成完整 dev2 格式**（会双重拉普拉斯）
- **单测（t14，制造场判据）**：三例手算期望值（U=(x²,0,0)→(2,0,0)；纯剪切→(0,2,0)；各向同性膨胀→(−0.5,0,0)）+ div-free 线性场闭合六面合量=0，全过
- **理论定位**（GLM F3）：常 ν 恒等式 `div(ν·dev2(T(∇U))) = (ν/3)∇(∇·U) ≈ 0`（不可压缩）——与网格正交性无关；预期 L1/L3 回归 ≪0.5%；价值主体=合同合规+D-6 候选证伪

## 2. WSS 二阶重构（D-7 关闭）

- **实现**：metrics.rs `wall_shear_stress_ex`——壁面法向三点二次重构（含 U_w=0 约束），体素堆叠显式系数 `τ_w = μ(9u₁−u₂)/(3Δ)`（u₁=贴壁 cell 切向速度、u₂=第二层、Δ=层距；GLM 提供的系数经抛物线自验）
- **双席修正**：方案一（非正交修正复用）在轴对齐体素网格上**恒为零**（Δ∥S_f）——零阶数增益，必须用方案二（GLM F5）
- **守卫与回退**：对层面用 away 方向鲁棒查找（不依赖墙面法向朝向）；层距比 ∈[2,4]（**FP epsilon 防边界排除——体素 ratio 恰 2.0，1.9999999999999998 曾被硬边界误拒，45% 面误回退**）；方向对齐 >0.9；sliver 守卫；回退一阶并计数（WssStats）
- **单测**：t15 二次剖面精确（相对误差 <1e-12）；t16 单层网格全回退且回退值=一阶
- **L0 解析门**（main.rs 门判定已含 WSS 三项）：
  - ny=41（细网格，现默认）：**+1.42% < 2% PASS**
  - ny=21：+2.61%（近壁边界面 O(dy) 截断——求解器既有属性，非重构缺陷）
  - **入口段修正**：FlowRateInlet 为均流 plug，入口发展段近壁速度虚高污染整patch 平均——门判定改为下游已发展段（x>0.5L）均值；修正前 6.02% → 修正后 2.61%（ny=21）
