## 关键设计决策（清洁室，依据文献）

1. SIMPLE：Patankar & Spalding；HbyA 由松弛后动量矩阵 A'·HbyA = b' 解得（欠松弛
   α_U=0.7 以"方程松弛"折入：A'=A/α，b'=b+(1/α−1)·A·U_old）；rAU = V/A'。
2. Rhie-Chow：phi_f = HbyA_f·Sf − rAU_f·k_f·(p_N−p_P)，k_f=Sf·Δ/|Δ|²（Rhie & Chow 1983）。
3. 定流量入口：均匀法向速度，方向 = patch 面积加权平均内法向，幅值 = Q/A_patch
   （保证 Σ_f phi = −Q 精确，与契约 E15 实证同构）。
4. 残差口径：mean|r|/mean|b|（对标 OpenFOAM gSum(cmptMag)/nCells 归一化）。
