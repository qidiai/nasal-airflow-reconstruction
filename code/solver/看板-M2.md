> 用 PCG-SGS。同样"relTol 0.05"下，GAMG 残差里高/低频都被压掉，PCG-SGS 只压掉高频，

#### W5.1-2 Rhie-Chow 在畸变 cell 上的自洽性 → **无缺陷**

逐项核对：`assemble_pressure` 的面系数 `d = interp(rAU)·k_f`、`diag += d / upper += −d`、
`source[o] −= φ_HbyA / source[nb] += φ_HbyA` 与 `rhie_chow_phi` 的 `−rAU_f·k_f·(p_N−p_P)`
严格同号（推导见 `fvm.rs` 文档注释）。pN6 上 `k_f` 恒正、`interp lam ≈ 0.5`，
RC 项不存在退化面。首步（U=0，纯 Darcy）给出的 dP = 24.2 Pa（≈归档 1472 Pa 的 1.6%），
这是"扩散主导"的启动步，量级远低于终值属正常（对流未打开）；随后 dP 在 2–3 步内
跃到 1600–2200 再回落到 1380–1470 平台——**这个过冲是 SIMPLE 启动的正常过程，不是发散**。

#### W5.1-3 bounded linearUpwind 的实际实现 → **两处真缺陷（已修，见 W5.2）**

(a) 延迟修正的**符号写反**：`source += +φ·dev` 应为 `−φ·dev`。按本文 `A·u=b`、`b=−(显式 LHS 项)`
约定，非正交修正项（`source += +ν(Sf·corr)`）与边界已知项（`source += −φ·u_b`）都是
"负号约定"，唯独内部面的高阶偏差用了正号 → 该项变成**反扩散**，量级 ≈ 2 倍迎风数值扩散，
而物理扩散 `ν·k_f` 只有它的 1/5 → 高 Péclet 必然振荡。
(b) 限示器**三分量取最严 θ**：`theta = min_i clamp(e_i/dd_i, 0, 1)`。
三维流动中只要有**一个分量**两端相等（`dd_i≈0`）而外插 `e_i≠0`，θ 立刻被压到 0，
整个面退回**一阶迎风**。pN6 上这条极常见 → 方案实际长期在一阶。
改为**逐分量限示**（三分量本就各解一个标量方程，共用系数矩阵，合法）。

#### W5.1-4 启动策略（pseudo-transient / Stokes 启动 / 松弛爬坡）→ **不需要**

实测默认 0.3/0.7 从 U=0 冷启动，1500 步全程稳定（无 NaN、无 ∞、无负体积、无 U 单调爆炸）。
另试 0.3/0.3 低松弛（200 步）亦稳定。**本算例不存在"启动即失稳"**，任务书第 4 条的
pseudo-transient 未启用（记录为已排除项，不是未尝试）。

#### W5.1-5 残差定义对拍 → **定义正确**

`res = mean|r|/mean|b|`；OpenFOAM `SolverPerformance::initialResidual()` 的归一化因子
`gSum(cmptMag(b))`，两边同除 nCells 后完全等价。故 pN6 的 `p 初残差 5e-3` 平台是**真实平台**，
不是口径错判；且与契约 §10"归档 1500 步从未触发 residualControl"同构。

## W5.4 第四棒：L1 耗散差收口（dP −5.2% → −0.13%）

### W5.4-1 【决定性】`bounded` 不是限示器（用户指南原文核对）

OpenFOAM 用户指南 §4.5.3（v9/v14 同文，`doc.cfd.direct/openfoam/user-guide-v9/fvschemes`）原文：

> **linearUpwind**: second order, upwind-biased, **unbounded** …
> The **bounded** variants of schemes relate to the treatment of the material time derivative
> … ∂e/∂t + ∇·(Ue) − (∇·U)e … At convergence ∇·U = 0 … Before convergence is reached …
> it is better to include the third term within a numerical solution because it helps maintain
> boundedness of the solution variable and promotes better convergence. **The bounded variant of
> the Gauss scheme provides this, automatically including the discretisation of the third term
> with the advection term.**

即：`bounded Gauss linearUpwind grad(U)` = **无界二阶迎风偏置面值** + **−（∇·U）e 稳态修正项**，
**不含任何限示器**。第三棒把 `bounded` 理解成 TVD 限示（把面值夹到 [U_c,U_d]），是**自创的额外耗散**，
正是 dP 偏低 5.2% 的主因（第四棒实验矩阵给出生死判据，见 W5.4-3）。

## 关键设计决策（清洁室，依据文献）

1. SIMPLE：Patankar & Spalding；HbyA 由松弛后动量矩阵 A'·HbyA = b' 解得（α_U=0.7 折入方程松弛：
   A'=A/α，b'=b+(1/α−1)·A·U_old）；rAU = V/A'_diag。
2. Rhie-Chow：phi_f = HbyA_f·Sf − rAU_f·k_f·(p_N−p_P)，k_f=Sf·Δ/|Δ|²（Rhie & Chow 1983）。
3. 对流（第四棒更正）：`bounded Gauss linearUpwind grad(U)` = **无界二阶迎风偏置面值**
   `u_f = u_c + (C_f−C_c)·∇u_c`（不限示）+ **bounded 稳态修正项**，即按
   `Σ_f φ_f u_f − u_P·Σ_f φ_f` 离散（用户指南 §4.5.3）。隐式部分用迎风系数，二阶偏差作显式
   延迟修正；`b = −(显式 LHS 项)`（见 §W5.1-3）。旧限示器仅保留为诊断开关。
4. 定流量入口：逐面单位内法向，幅值 = Q/ΣA（与 OpenFOAM flowRateInletVelocity 同构）。
5. 残差口径：mean|r|/mean|b|（= OpenFOAM gSum(cmptMag)/gSum(cmptMag)，已核）。
6. WSS（契约 §11 一阶体素估计）：tau = mu·|(I−nnᵀ)U_c| / d_n，`d_n = |C_f − C_c|`
   （第四棒 B6 更正；旧 V/(2A) 在部分壁面上失效）。
