# DICOM 输入规范（V1.0 §5.1 五项对照 · 一页纸）

| §5.1 要求 | 本项目状态 | 证据 |
|---|---|---|
| ① 层厚 ≤1mm | ✅ 0.349609 mm（优于推荐 2.9 倍） | DICOM PixelSpacing 实测（394 文件一致） |
| ② 扫描范围覆盖鼻尖至鼻咽 | ✅ 全覆盖（394 层，鼻尖至鼻咽端） | 序列首末层解剖位置 |
| ③ 平扫（无造影剂） | ✅ 平扫 | 脱敏数据包说明 |
| ④ 重建算法：骨算法或标准算法 | ✅ 双序列在包：ISO_Soft_0.35mm（软组织/标准核）+ ISO_Bone_0.35mm（YB 骨核）各 394 层 | 患者A\脱敏后图像数据\ |
| ⑤ 文件格式：DICOM | ✅ 标准 DICOM，788 文件逐头核验 PII 为空 | 匿名化核验记录-20261002.md |

**双序列选择说明**：pipeline 选 **ISO_Soft**（step1_airway_segment.py 路径配置）——气道与黏膜为软组织结构，软组织核重建的噪声-对比特性适配 HU 单阈值分割（−400，§5.3 允许口径"有技术称 −400，需按实际情况微调"）；**ISO_Bone 序列保留在包**，可复跑用于骨性结构对照与骨窗验证（管线切换序列仅需改一行路径配置）。

**输入检查**：step1 导入时逐层校验（层数一致性/几何参数/IOP 方向），异常即中止；匿名化状态见《匿名化核验记录-20261002.md》（788 文件逐头断言，核心 PII 全空）。
