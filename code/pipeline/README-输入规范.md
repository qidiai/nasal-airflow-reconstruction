**双序列选择说明**：pipeline 选 **ISO_Soft**（step1_airway_segment.py 路径配置）——气道与黏膜为软组织结构，软组织核重建的噪声-对比特性适配 HU 单阈值分割（−400，§5.3 允许口径"有技术称 −400，需按实际情况微调"）；**ISO_Bone 序列保留在包**，可复跑用于骨性结构对照与骨窗验证（管线切换序列仅需改一行路径配置）。

**重叠重建与实测间隙口径**：赛事提供 CT 的软组织序列头标 `SliceThickness` = 0.5 mm，而 `ImagePositionPatient` 实测逐层间隙中位 = min = max = 0.3 mm（420 个 .dcm 文件、419 个间隙）——属**重叠重建**，头标层厚≠逐层采样间距，故本管线只认实测间隙、不信头标。口径统一：step1 的 `dz` 取 `airway_geom.py#z_gap_report` 的中位间隙（`step1_airway_segment.py:91`），体积换算 `vox_vol`、`marching_cubes` spacing、QC 图 aspect 与预检 `slice_gap_measured`（`run_all.py:403`；总控报告在 `run_all.py:969` 仍消费它）用的是**同一个数**，不再取最底两层。为什么改成门：旧实现只取最底两层算 dz，缺层时数字静默失真——首间隙翻倍会让气道体积恰好变 **2.0 倍**（体积 ∝ dz），且旧预检 `z_structurally_ok` 全程放行；现改为停工上报。真实数据 16 个序列目录上，旧口径 `dz_now`（最底两层）与新口径 `dz_new`（中位间隙）逐目录相等（最大相对差 3.248e-13）——已交付病例数字未因本次改动移动。

**输入检查**：step1 导入时逐层校验（层数一致性/几何参数/IOP 方向），异常即中止；匿名化状态见《匿名化核验记录-20261002.md》（788 文件逐头断言，核心 PII 全空）。层间距一致性门在 step1 位于体素数组分配之前（`step1_airway_segment.py:93-97` 门 / `:98` 分配），停工时不分配体素、不产出任何 `metrics*_v2.json`；总控预检 `run_all.py#survey_dicom` 用同一个中位数与同一容差在 `run_all.py:450` `die(2, …)`；web 上传路径由 `server.py:2150-2152` 捕获 SystemExit、`server.py:2157-2163` 落 `blocked` / `exit_code=2` ⛔ 拦截卡。
