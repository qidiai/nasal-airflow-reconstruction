了解空鼻症（ENS）

"检查都正常，可你就是喘不上气。" —— 空鼻症患者最常说的那句话

空鼻症（ENS）：下鼻甲手术后，CT 和鼻内镜看起来"都正常"，但每时每刻都觉得喘不上气。 传统检查只看结构，不显示空气怎么流。患者最痛的不是症状，是"检查都正常，医生觉得你没事"——不被相信。

我们的观点：把主观的"喘不上气"，变成可以看见、可以比较的气流数据。 同一份 CT → 三维气道 → 流体仿真 → 每个截面的气流速度/压力/阻力。 患者A 实测：压降 ΔP = 18.45 Pa（常人带 30–150 Pa）——"过度通畅"第一次有了数字。

我们看的三件事（患者语言）

💨气流是否均匀
空气流过鼻腔每个截面时，分布均不均匀——有没有"一股独大"的窄道。
技术细节
检查气流是不是一股脑冲进一边、另一边没气（统计口径已定义，逐截面统计开发中）。
🔍有没有"死区"
鼻甲区有没有气流几乎不经过的小角落——那里的感觉可能最"空"。
技术细节
检查该有“通气感”的地方是不是感觉不到气流（统计口径已定义，开发中）。
🖐鼻腔内壁摩擦力
气流滑过鼻腔内壁的“抚摸感”——太弱了大脑就感觉不到在呼吸（空鼻症的核心）。
技术细节
壁面剪切应力（WSS）：壁面处速度梯度 × 流体黏度，单位 Pa；报均值与 p95。

边界与已知局限

  • 温湿度交换未建模——仅气流场（速度/压力/摩擦）仿真，质传递是进阶项，列入路线；
  • 医生侧本版未验证——本版为患者/操作员/评委视角；医生侧闭环（诊室只读指标视图）列为用户行动项，不作沉默缺位；
  • 数值口径：压降 ΔP 为定流量口径（固定 15 L/min 流量测得），阻力 R 为等压口径（两侧等压迭代自然分流测得）——两个口径数值不可互换；常人对照带为文献量级对照，非同机制对照；
  • 观众交互边界：观众自助浏览与 CT 原图切片范围待确认；确认前三平面 QC 仅掩膜/掩膜叠加态，皮肤层默认关。
责任边界（固定句）：本工具为科研与康复参考，非医疗器械；仿真几何与结果禁止人体使用； 不构成诊断、治疗或试戴建议。"过度通畅"与 ENS 的临床关联，待主诊医师复核。

  • 🛡️ 患者衍生静态数据闸：云形态下 /static/cases/*、/static/models/*、/static/plus/* 一律 403（static_patient_gate，代码级）。
  • 🔒 PII 硬闸：真实 CT 逐文件头信息断言，出现未脱敏身份字段即停工（PII 拦截指引卡）。
